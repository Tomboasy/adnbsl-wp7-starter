# Icônes

Préférer :

- SVG locaux (ce dossier ou `sprite.svg`) ;
- icônes Dashicons uniquement dans l’admin ;
- aucun FontAwesome global.

`sprite.svg` contient quelques symboles de référence (`icon-arrow-right`,
`icon-close`, `icon-chevron`). Les utiliser via `<use href="#…">` uniquement
si le sprite est injecté dans la page.

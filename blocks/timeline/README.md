# Timeline — structure réservée

Aucun CPT. Si un projet a besoin d’une frise, commencer par :

1. Pattern de Core Blocks (colonnes + séparateurs) ;
2. Query Loop si le contenu est des articles.

Ce dossier n’enregistre pas de bloc tant qu’un `block.json` n’est pas ajouté.
`inc/blocks.php` ignore les dossiers sans `block.json`.

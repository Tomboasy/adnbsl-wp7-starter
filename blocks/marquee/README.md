# Marquee — structure réservée

Un bandeau défilant se fait souvent en CSS (`overflow` + animation) autour
d’un `core/gallery` ou `core/group`.

N’ajouter un custom block ici que si l’interaction (pause au focus, réduction
de mouvement, duplication du contenu pour une boucle fluide) le justifie.

Sans `block.json`, ce dossier n’est pas enregistré.
